# Battle worlds and guardian motion

Approved by the user on 2026-10-27 after viewing an arena triptych and six Oxygenator poses.

Six original battle-only environments: RCP103 pulmonary mountain amphitheater, RCP104 apothecary vault, RCP201 neonatal sanctuary, RCP202 critical-care foundry, RCP203 diagnostic observatory, and Vitals Titan's final-protocol sanctum. Keep navy/teal/brass art language, clear central ground, and readable question UI. Never reuse menu or course-banner illustrations as battle scenery. Both regular battles and the Titan encounter use this system at mobile and desktop widths.

All 57 stable guardian IDs receive a true-alpha 3-by-2 sheet of six individually drawn poses: neutral, inhale, wind-up, strike, recoil, recovery. Preserve existing identities and medical equipment. Idle plays neutral/inhale slowly with feet anchored; attacks play wind-up/strike/recovery; received hits show recoil/recovery. Flying/spectral creatures may hover naturally but cannot substitute whole-image bobbing for anatomical pose changes. Existing slash, damage, shield, critical and finisher effects accompany those poses. Attack and hit sequences interrupt idle, then return to it. Standalone menus/prep portraits remain static artwork.

A focused BossMotion engine loads each atlas on demand, preserves the original image until decode, owns cancellable pose timers and restores originals on failed load. Existing arena APIs remain compatible. Arena art is selected from stable course IDs, Titan explicitly. Router navigation and screen-local rerenders cancel outstanding visual sequences. Existing battle save/reward/question rules remain intact; guard answered questions against repeated input. Paused ambience, OS reduced motion and hidden document stop pose timers and large screen FX. Decorative sprites remain aria-hidden; retain text feedback and player-controlled regular-battle advance.

Validate all six arena assets and all 57 sheets for alpha, dimensions, distinctness, content/ID alignment, pose differences, visible floor anchors and precache coverage. Verify responsive regular/Titan battles, real correct/incorrect/shield/crit/finisher events, pause and preference changes, navigation during attacks, image failure fallback and offline reload. Review code with Claude, run existing engine tests, then publish and verify production hashes. Original generated sources and prompts are documented with the art; Obsidian holds session memory.
